# BYOC (Bring Your Own Cloud) Service

This package contains Terraform resources and data sources for managing BYOC dataplanes and engines.

## Resources

- `ibm_byoc_dataplane` - Manage BYOC dataplanes
- `ibm_byoc_engine` - Manage BYOC engines

## Data Sources

- `ibm_byoc_dataplane` - Read BYOC dataplane information
- `ibm_byoc_dataplanes` - List BYOC dataplanes
- `ibm_byoc_engine` - Read BYOC engine information
- `ibm_byoc_engines` - List BYOC engines

## API Documentation

The BYOC service provides APIs for managing dataplanes and database engines in a bring-your-own-cloud model.
